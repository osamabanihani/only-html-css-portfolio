# Osama Banihani Portfolio

A responsive personal portfolio built with semantic HTML5 and clean CSS3 only.

## Sections

- Navigation and hero
- About
- Experience
- Qualification
- Technical and soft skills
- Projects
- Certificates with full PDF copies
- Professional references
- Contact footer

## Run locally

Open `index.html` in any modern browser. No installation or build step is required.

## Technologies

- HTML5
- CSS3 (Grid, Flexbox, custom properties and media queries)

## Deployment

This static website can be published directly with GitHub Pages.
